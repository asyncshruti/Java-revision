# Java Revision

This repository contains my Java revision notes, code implementations, and practice programs based on the Apna College Java playlist.

The objective is to strengthen my understanding of Java fundamentals, Object-Oriented Programming, and core programming concepts while building a strong foundation for Data Structures and Algorithms.
